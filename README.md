# AVR Temperature-Controlled Fan

Temperature measurement and fan control with a multiplexed three-digit display and timer interrupts.

**Technology:** Embedded C and ATmega328P.

## Run or inspect

Open `Finial Project.atsln` in a compatible Atmel/Microchip Studio AVR development environment. The original spelling and relative project paths are retained.

The project targets ATmega328P. Its source is `Finial Project/222257U_Project_1-02-2024.c`. Use hardware and clock settings matching the original project. Build and flash locally; generated firmware and debug outputs are excluded from this repository.
